# common-issues-patterns

torch-npu 社区常见问题、审核模式、典型错误与解决方案汇总

## 内容结构

- **SKILL.md** - 主知识文件，包含：
  - §0 问题分类（5 个维度）
  - §1 环境与依赖问题（版本匹配/权限/环境变量）
  - §2 API 兼容性问题（算子不支持/in-place/参数差异）
  - §3 精度问题（FP16溢出/累积误差/融合精度）
  - §4 性能异常（利用率低/内存泄漏/首次推理慢）
  - §5 PR 审核常见反馈模式
  - §6 快速诊断流程
  - §7 参考资源

## 适用场景

- 迁移报错快速定位
- 精度/性能问题诊断
- PR 提交前自查
- 代码审查参考清单

## 问题覆盖

- ✅ 环境配置（30% 问题）
- ✅ API 兼容性（25% 问题）
- ✅ 数值精度（20% 问题）
- ✅ 性能调优（15% 问题）
- ✅ 运行时错误（10% 问题）

## 审核模式

基于社区实践提炼：
- 代码质量（类型标注/错误处理/日志规范）
- 测试覆盖（单元测试/精度测试/边界测试）
- 文档完整性（README/CHANGELOG/示例）
- 性能要求（Benchmark/Profiling/回归测试）
- 兼容性（版本/向后兼容/跨平台）
