# 数据来源与合规说明

**作品**：CodeVigil Agent · **队伍**：三三队

## 1. 数据分类与来源

| 数据类型 | 来源 | 用途 | 是否入库提交 |
|----------|------|------|--------------|
| PR / Issue 正文与评论 | GitHub / GitCode **公开 API**（用户授权 Token 时） | 单次审查取证 | 否（运行时拉取） |
| CI check-runs 摘要 | GitCode 公开接口 | 归因与报告 | 否 |
| 本地粘贴文本 / 日志 | 用户主动粘贴 | `/ci`、本地审查 | 否 |
| Skills 知识正文 | 本仓库 `.cursor/skills` + 可选官方公开 skill 包 | 专业路由上下文 | 技能文件随开源仓；官方包装用户目录 |
| 昇腾文档 | `ascend-doc-mcp` 运行时检索 | 文档查证 | 不 vendoring 进主体 |
| 社区采集结果 | `collect` → 本地 `data/` | 研究/复盘 | **不**作为参赛 zip 内容提交 |

## 2. 合规原则

1. **最小必要**：默认只读调查；写盘与推送须用户逐步确认。  
2. **密钥隔离**：GitCode Token 与 GitHub Token 分平台使用，禁止混用。  
3. **不提交秘密**：参赛材料不含 `.env`、私钥、真实 Token、未脱敏日志。  
4. **开源许可**：主体 MIT；第三方依赖与官方 skill/MCP 保持可追溯，不隐瞒来源。  
5. **无统一官方数据集依赖**：符合赛事 FAQ 常见口径——不依赖组委会统一数据集。  
6. **用户数据**：演示与截图脱敏；采集数据默认留在用户本机。

## 3. 第三方与官方组件关系

| 组件 | 关系 | 说明 |
|------|------|------|
| 本仓库编排 / 路由 / Git / MCP 客户端 / 采集 | 自研 | 参赛主体 |
| `torch-npu-*` 等官方 skill（可选安装） | 公开来源 | 安装至 `~/.reviewagent/skills/` |
| `ascend-doc-mcp` | 运行时 `npx` 拉取 | 不打进主体包 |
| 大模型 API | 用户自备 | 按各厂商条款使用 |

## 4. 演示与截图说明

- PPT / 配套「界面示意」中的终端图为本机 Windows PowerShell **实机窗口捕获**。  
- 展示命令包括：`reviewagent --version`、`/help`、`/skill list`、`/mcp`、unittest 等。  
- 不含真实用户隐私与密钥。
