# 系统架构说明

**作品**：CodeVigil Agent（CLI：`reviewagent` / `ra`）  
**队伍**：三三队 · 赛道 Coding（兼科研）  
**版本**：v1.8.0 · 许可证 MIT

## 1. 架构总览

采用 **「对话编排 + 专业规则 + 只读工具 + 显式生产力」** 四层结构：

```text
┌──────────────────────── 用户终端 ────────────────────────┐
│  reviewagent / ra（Hermes 风格 CLI）                      │
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌────────────────── ConversationAgent ─────────────────────┐
│  AI自动调换：light / infra / general                     │
│  会话：/new /back /sessions                              │
│  扩展：Skills 挂载 · MCP 注册表                          │
└──────────┬───────────────────────────────┬───────────────┘
           │                               │
           ▼                               ▼
┌─ 专业路由 specialist_context ─┐  ┌─ 调查循环 investigate ─┐
│ operator | inference          │  │ web_search（门控）      │
│ opengauss                     │  │ local_search（只读）    │
│ → .cursor/agents + skills     │  │ fetch_pr_issue（只读）  │
└──────────────┬────────────────┘  │ mcp_call（只读Hint）    │
               ▼                   └───────────┬─────────────┘
┌─ SmartReviewer / patch_fix ─┐              │
│ 报告 · 补丁预览 · 来源追溯     │◄─────────────┘
└──────────────┬────────────────┘
               ▼
┌─ git_work 生产力链 ───────────┐
│ /fix→/apply→/commit→/push    │
│ /pr 或 /ship（逐步确认）       │
│ 禁 force / amend               │
└───────────────────────────────┘
```

## 2. 与 openJiuwen 概念映射（说明用，非声称已接入）

| openJiuwen 概念 | 本作品对应实现 |
|-----------------|----------------|
| ReActAgent | `investigate`：Thought→Tool→Observe，最多 3 步 |
| WorkflowAgent | `/fix→/apply→/commit→/push→/pr` 与 `/ship` |
| Skills | `.cursor/skills` + `/skill install` |
| MCP | stdio JSON-RPC；内置 `ascend-doc` |
| WorkSwarm / Studio | DEMO 阶段可选演进，创意阶段如实标注未接入 |

## 3. 关键数据流

1. **输入**：自然语言、GitHub/GitCode URL、粘贴日志、斜杠命令。  
2. **调换**：含 Infra 证据时进入审查车道，否则保持轻量闲聊。  
3. **取证**：拉取 PR/Issue/CI；必要时 MCP 查昇腾文档。  
4. **路由**：算子 / 推理 / openGauss 加载对应 Skills（有预算上限）。  
5. **输出**：可证实问题与建议；写盘必须经确认链。

## 4. 部署视图

| 组件 | 形态 | 说明 |
|------|------|------|
| CLI | npm 全局 / 本地 `node bin/reviewagent.js` · `start-reviewagent.bat` | 终端入口 |
| 桌面版 | `启动桌面版.bat` · `desktop-app/win/` · macOS arm64 | 聊天 / 审查 / 设置 |
| 核心 | Python 3.7+（`ascend_cli.py` 等） | 编排与工具 |
| 模型 | 用户自备 API（多 Provider，可下拉切换） | 不绑定单一云 |
| Skills / 自定义命令 | 项目内 + `~/.reviewagent/` | 不污染待审仓 |
| MCP | 固定 `ascend-doc-mcp@1.0.1` + 进程信任确认 | 运行时拉取 |

配套界面示意见 `界面示意/` 目录中的本机实机截图与架构图 PNG。
