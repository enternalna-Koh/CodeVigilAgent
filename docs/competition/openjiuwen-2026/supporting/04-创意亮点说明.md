# 创意亮点说明

**作品**：CodeVigil Agent · **队伍**：三三队 · **赛道**：Coding（兼科研）

## 一句话

不是「会聊天的助手」，而是能在昇腾 / AI Infra 场景里**取证、路由专业规则、查文档、给补丁并在确认后交付**的 Agent。

## 亮点 1：AI 自动调换 + 三条专业路由

- 闲聊保持轻量；贴上 GitHub/GitCode 链接或昇腾关键词时自动进入 Infra 审查车道。  
- 算子社区 / 推理部署 / openGauss 三条路由，按证据分流，含糊则提问不猜。  
- **价值**：减少「通用模型不懂社区口径」的无效对话。

## 亮点 2：Skills × MCP 双轨扩展

- Skills：项目内知识包 + `/skill install` 官方 `torch-npu-*` 等，装到用户目录，**不污染待审仓库**。  
- MCP：内置昇腾文档 `ascend-doc`，调查循环自动调用须 `readOnlyHint=true`。  
- **价值**：文件技能与在线文档互补，可演进、可追溯。

## 亮点 3：安全默认的生产力链

- 调查阶段只读；本地改动必须 `/fix` → 预览 → `/apply` → `/commit`/`/push`/`/pr` 或 `/ship`。  
- 禁止 force push / amend；Token 按平台隔离。  
- **价值**：适合开源社区与企业合规，避免「模型直接改仓」。

## 亮点 4：社区知识可沉淀（科研兼报）

- `collect` 采集 issues/PRs/CI/师生审核对话，服务导师复盘与口径统一。  
- openGauss 场景证明范式可迁移，不只绑单一仓库。  
- **价值**：把「审核经验」从口头变成可引用资产。

## 亮点 5：工程可复现，而非 PPT 空想

- 已开源 MIT；CLI 可一键安装；大规模离线回归 + CI。  
- 报告带预算与来源标记；材料对未验证项（如上板精度）**诚实披露**。  
- **价值**：评委与用户可按仓库复现主路径。

## 亮点 6：桌面版 + 终端体验与安全加固（近期）

- Windows / macOS 桌面应用：持久聊天、结构化审查、模型下拉切换。  
- 自定义斜杠命令、`@文件` 提及、pre-commit 门禁、`/cost` 用量统计。  
- MCP 进程信任确认、固定 `ascend-doc-mcp` 版本、补丁与审计安全修复。  
- 终端边框按字体定位对齐，中英文混排可读。

## 与常见方案对比（摘要）

| 类型 | 常见短板 | CodeVigil |
|------|----------|-----------|
| 通用 Chat / IDE 插件 | 不懂昇腾验收与 GitCode 工作流 | 垂直路由 + 取证 |
| 纯规则扫描 | 难引用社区案例与文档 | Skills + MCP |
| 自动改仓助手 | 合规风险高 | 只读默认 + 显式确认 |

## 非亮点（边界，避免误解）

- 不替代真实 NPU 上板与官方精度门禁。  
- 创意阶段**未**声称已深度接入 openJiuwen WorkSwarm；DEMO 阶段可演进。  
- 不提交真实 Token 与未脱敏用户数据。
