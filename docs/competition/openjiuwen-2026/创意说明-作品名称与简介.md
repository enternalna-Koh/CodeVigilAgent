# 作品名称与项目简介

## 作品名称

**CodeVigil Agent**  
副标题：面向昇腾 NPU / AI Infra 的审查、排障与生产力智能体

（产品对外品牌；npm / CLI 唤醒名仍为 `reviewagent` / `ra`。）

## 一句话定位

把「能对话」的大模型，变成能在昇腾生态里**真正干活**的 Agent：读 PR/Issue、路由专业规则、查文档 MCP、给补丁预览，并在用户确认后走 commit / push / PR；同时提供 **Windows/macOS 桌面版** 与打磨过的终端 UI。

## 项目简介（可直接粘贴报名表，约 380 字）

昇腾开发者日常深陷三类摩擦：社区任务验收口径散落在多个仓库与讨论区；CI / 审核人对话与本地案例难以复用；通用聊天助手「会说不会做」，无法安全落地到 Git 工作流。

CodeVigil Agent 是一款 Hermes 风格智能体（CLI + 桌面版），默认 **AI 自动调换**：闲聊保持轻量，贴上 GitHub / GitCode 链接或昇腾关键词时自动进入 Infra 审查车道。内置算子社区、推理部署、openGauss 社区三条专业 Agent 路由，按需加载 Skills；内置昇腾文档 MCP（`ascend-doc`，固定版本与进程信任确认），支持 `/skill` 安装官方 `torch-npu-*` 技能。调查循环仅自动调用只读工具；本地改动必须经 `/fix` → 预览 → `/apply` → `/commit` / `/ship`，禁止 force push / amend。

近期增强：自定义斜杠命令、`@文件` 提及、pre-commit 门禁、`/cost` 用量、模型下拉切换、终端边框对齐与桌面聊天/审查界面。已开源（MIT），仓库 [`CodeVigilAgent`](https://github.com/enternalna-Koh/CodeVigilAgent)，配套大规模离线回归，面向学生、社区贡献者与企业 AI Infra 工程师。

## 英文短简介（可选）

CodeVigil Agent is an Ascend AI-Infra agent (CLI + desktop) that reviews PRs/Issues, loads specialist skills, queries Ascend docs via MCP, and ships changes only after explicit user confirmation—with trusted MCP, custom commands, @file mentions, and a polished terminal/desktop UX.
