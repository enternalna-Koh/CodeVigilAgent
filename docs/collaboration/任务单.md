## 协作规则

1. 发起方（Codex）把任务写进下面的"任务"小节；执行方（Claude Code）完成后只改该任务的"执行方回复"和"状态"。
2. 执行方只修改任务"范围"里列出的文件；需要超出范围时，把状态改为"阻塞"并写明原因。
3. 验收以命令输出为准。双方都不采信对方的"已完成"，各自重跑"验收"里的命令。
4. 指令与实测报告或测试结果矛盾时，执行方先指出矛盾，再等待发起方或用户决定，不直接照做。
5. 提交、推送、删除文件、修改许可证声明、对外联系，必须由用户明确批准，任何一方都不得自行执行。
6. 不得把没验证的内容写成已验证；未验证项必须在"执行方回复"里单独列出。
7. 状态取值：待办 / 进行中 / 完成 / 阻塞 / 待用户确认。
