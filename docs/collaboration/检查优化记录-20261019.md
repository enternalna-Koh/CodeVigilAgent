## 实际边界与未验证

测试使用 Windows、本地临时仓库/会话、mock HTTP 与本地 Python MCP 假服务端；清除真实模型/平台凭据并隔离 REVIEWAGENT_HOME。没有真实模型计费、真实 GitCode 采集或远端 MCP 包安装。没有新增依赖、改变第三方许可、迁移旧采集文件或发布 npm。

MCP readOnlyHint 是服务端声明，不能证明恶意服务无副作用；自定义命令按用户账户环境启动。MCP 真实 ascend-doc 包、Linux/macOS、旧 Python、NPU/CANN、审查准确率和全新 npm 安装未验证。

技能 references 当前保存为本地材料，尚不自动注入模型；原文不完整或超预算会拒绝挂载。下载全部成功才开始写入，但多文件写入并非事务，磁盘中途失败会返回错误，可能留下部分写入。采集保留失败资源旧文件，成功资源可更新，不承诺整批事务；旧命名与新命名数据同时存在，后续需按来源识别重复。

历史版本矩阵的来源冲突保持任务单原有未核验状态，未将离线测试写成实机兼容结论。
